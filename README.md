# Стоя | Stoa — стоический ежедневник

**Стоя (Stoa)** — responsive web-приложение (мобильные устройства и ноутбуки), объединяющее четыре функции:

1. **Стоический ежедневный планировщик** — утренняя подготовка и вечерний разбор дня (по Сенеке и Марку Аврелию);
2. **Мотивационный гид** — библиотека стоических практик, цитаты и ежедневные уроки;
3. **Личный дневник** — записи с промптами, настроением и тегами;
4. **Менеджер личных задач** — задачи в разрезе «дихотомии контроля» (что в моей власти / что вне её).

Проект учебный / портфолио-ориентированный, с полным циклом разработки: исследование → ТЗ → архитектура → user stories → wireframes → UI-черновики → бэкенд → тест-кейсы → план сборки → MVP.

## Ключевые решения

- **Бэкенд**: облако, **Supabase (бесплатный тир)** — Postgres + Auth + RLS + Storage, $0. Уровень данных реализован как адаптер: в демо-режиме работает localStorage-адаптер (без ключей), при наличии `NEXT_PUBLIC_SUPABASE_URL` подключается Supabase.
- **Фронтенд**: **Next.js 15 + TypeScript + Tailwind CSS**, хостинг Vercel (бесплатный).
- **Языки**: русский + английский (next-intl, локали /ru и /en, переключение на лету).
- **Приватность**: дневник — чувствительные данные; Row Level Security на уровне БД, экспорт и удаление аккаунта по требованию.
- **Философия UX**: спокойный минимализм без «виноватой» геймификации (без штрафов за пропущенные дни).

## Запуск приложения

```bash
cd web
npm install
npm run dev        # http://localhost:3000 (редирект на /ru)
npm test           # юнит-тесты бизнес-логики (vitest)
npm run build      # производственная сборка
```

Демо-режим: аккаунт хранится локально в браузере (LocalAdapter, `web/src/lib/store.tsx`).
Боевой режим: задайте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` — см. [docs/07-backend.md](docs/07-backend.md).

## Прототип

Статический hi-fi прототип этапа дизайна: [`prototype/index.html`](prototype/index.html) — откройте в браузере или запустите `npx serve prototype`. Текущая живая версия дизайна — в приложении `web/`.
