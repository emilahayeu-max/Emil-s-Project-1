# 06. UI-дизайн: дизайн-система и черновые макеты

> Hi-fi слой. Реализован в интерактивном прототипе [`prototype/index.html`](../prototype/index.html) — откройте его, чтобы «пощупать» дизайн (переключение RU/EN, светлая/тёмная тема, все экраны, mobile/desktop).

## 1. Дизайн-принципы

1. **Спокойствие через минимализм** — интерфейс «тише» пользователя: ничего не мигает, не кричит, не давит.
2. **Стоическая эстетика**: мрамор, папирус, бронза, тушь. Античная образность без «дешёвого неоклассицизма» (никаких гипсовых колонн в каждой кнопке — только типографика, цвет и воздух).
3. **Текст — главный интерфейс**: цитаты и промпты набраны шрифтом с засечками, крупно, с большим межстрочным интервалом — продукт «про чтение и письмо».
4. **Мягкая мотивация**: тёплые, «дышащие» акценты; нет тревожных красных бейджей и счётчиков-должников.
5. **Приватность как часть дизайна**: замок 🔒 у дневника — постоянный, заметный, успокаивающий.

## 2. Дизайн-токены

### 2.1. Цвет — две темы

| Токен | Светлая («Мрамор») | Тёмная («Тушь») | Назначение |
|---|---|---|---|
| `bg` | `#F5F2EA` (папирус) | `#14161A` (тушь) | фон |
| `surface` | `#FFFFFF` | `#1E2126` | карточки |
| `surface-2` | `#EDE8DC` | `#262A31` | вложенные блоки |
| `ink` / `text` | `#1F242A` | `#E9E4D8` | основной текст |
| `text-soft` | `#5B6470` | `#9AA3AE` | вторичный |
| `accent` (бронза) | `#A97E4F` | `#C89B63` | главная кнопка, ссылки |
| `accent-ink` | `#FFFFFF` | `#14161A` | текст на accent |
| `sage` (шалфей) | `#5E7A5E` | `#86A386` | успех, «в моей власти» |
| `clay` (терракота) | `#B0664E` | `#C98066` | «вне моей власти» (не «ошибка»!) |
| `line` | `#E2DCCE` | `#33383F` | границы |
| `focus` | `#A97E4F` | `#C89B63` | кольцо фокуса |

Контраст: основной текст на фоне ≥ 7:1 (AAA), вторичный ≥ 4.5:1 (AA).

### 2.2. Типографика

| Роль | Шрифт | Пример |
|---|---|---|
| Display (цитаты, заголовки экранов) | **Cormorant Garamond** (serif), 500–600 | 28–36 px, lh 1.25 |
| Текст интерфейса | **Inter**, 400/500/600 | 14–16 px, lh 1.5 |
| Размеры | База 16 px, шкала 12/14/16/20/24/32/40 | — |

### 2.3. Форма и пространство

| Токен | Значение |
|---|---|
| Сетка отступов | 4-pt: 4/8/12/16/24/32/48 |
| Радиусы | `r-sm` 8, `r-md` 12, `r-lg` 16, карточки-цитаты `r-xl` 20 |
| Тени | мягкие, «свет изнутри»: `0 1px 2px rgba(31,36,42,.06)`, `0 8px 24px rgba(31,36,42,.10)` (тёмная — едва заметные) |
| Тап-таргеты | ≥ 44×44 px |
| Макс. ширина контента | 720 px (текст), 1120 px (канбан) |
| Брейкпоинты | `sm` 640, `md` 768, `lg` 1024, `xl` 1280 |

### 2.4. Анимация

Медленные, плавные переходы (Framer Motion): появление карточек 200–300 мс `ease-out`, смена экранов 250 мс с лёгким fade+slide 8 px, нажатия 120 мс. Никаких «прыгающих» скелетонов — только спокойное затухание.

## 3. Компоненты

| Компонент | Описание |
|---|---|
| `Button` (primary/ghost/text) | Primary — бронза, скруглённая 12, полная ширина на мобильном |
| `Card` | Белая/тушевая поверхность, r-md, мягкая тень |
| `QuoteCard` | Цитата: кавычки-декор «❝», serif 24–32 px, автор и источник мельче, кнопки 🔖 (в избранное) и ↻ (другая цитата) |
| `PromptCard` | Промпт: вопрос serif + кнопка «✨ дайте промпт» |
| `TaskRow` | Чекбокс-кружок + заголовок + бейджи приоритета и метки контроля (⭕/◌) + свайп-жест на статус (desktop — кнопки) |
| `MoodPicker` | 5 смайлов 😞😐🙂😄🤩, крупные тап-зоны |
| `TagChip` | `#метка`, r-sm |
| `BottomNav` | 5 пунктов, иконка + подпись, активный — бронза |
| `Sidebar` (desktop) | Логотип, пункты, внизу — язык и тема |
| `EmptyState` | Спокойная иллюстрация + фраза-подсказка («День чист. Напишите намерение.») |
| `Toast` | Мягкие подтверждения (2 с), не ошибки-крикуны |
| `Sheet` (шторка) | Для «Ещё» и быстрых действий |

## 4. Ключевые экраны (описание hi-fi)

1. **Онбординг** — 3 карточки: «Утро. Намерение», «День. Дела под контролем», «Вечер. Честный разбор». Тёплая иллюстрация (мраморная колонна с тенью), кнопка «Далее» — единственный акцент.
2. **Сегодня (утро)** — приветствие «Доброе утро, Артём», большая QuoteCard, поля «Намерение» и «Препятствия» без рамок (только нижняя линия), чек-лист 3 главных задач, кнопка «Завершить утро».
3. **Сегодня (вечер)** — 4 вопроса разбора + карточка автоитогов дня (✅ 4 из 5, 1 — вне контроля) + «Сохранить разбор».
4. **Дневник** — лента карточек с датой, иконкой типа, настроением и тегами; FAB «⊕»; редактор с типами записи и промптом.
5. **Задачи** — переключатель «Список | Доска»; в списке — TaskRow с метками контроля; на доске — 3 колонки (К выполнению / В работе / Готово).
6. **Гид** — сетка карточек практик с категориями; карточка практики — шаги с номерами, «Выполнить» ведёт в редактор записи.
7. **Прогресс** — крупная цифра стрика 🔥, недельные счётчики, «мягкая» формулировка при пропуске: «Возвращаться — тоже практика».

## 5. Статус и следующий шаг

Черновые макеты реализованы в интерактивном прототипе (`prototype/index.html`): это не продакшен-код, а «живые» hi-fi макеты для проверки гипотез дизайна. После утверждения переносим в компонентную базу Next.js (спринт 1, [09-build-plan.md](09-build-plan.md)).
