# 09. План сборки и контент-план

## 1. Подход

- Один разработчик, гибкий график; этапы измеряются не днями, а **спринтами по 1–2 недели** (можно растягивать).
- Каждый спринт заканчивается **рабочим инкрементом** (демо на Vercel), а не «кодом в столе».
- Приоритеты — из ТЗ ([02-spec.md](02-spec.md)): сначала критический путь (аккаунт → цикл дня), потом ширина.

## 3. Контент-план

Контент — это половина продукта: без качественных цитат и практик «философский» слой превращается в декорацию. Принципы:
- переводы/адаптации из первоисточников (Марк Аврелий «Размышления», Сенека «Письма к Луцилию», Эпиктет «Энхиридион» — тексты в общественном достоянии);
- каждый элемент — на RU и EN;
- ротация без повторов (промпты ≥ 14 дней, цитаты ≥ 30 дней).

| Единица контента | Объём MVP | Структура | Источники |
|---|---|---|---|
| Цитаты | **100 шт.** (50 авторов-ядер) | автор, `text_ru`, `text_en`, источник, теги | Марк Аврелий, Сенека, Эпиктет, + Зенон/Клеанф/Мусоний Руф |
| Практики | **12 шт.** | название RU/EN, суть, категория, длительность, 3–6 шагов RU/EN, пример | дихотомия контроля, негативная визуализация, memento mori, amor fati, взгляд сверху, добровольный дискомфорт, вечерний разбор Сенеки, предвосхищение препятствий, благодарность, роль-модель (жить по образцу), молчание и слушание, «что зависит от меня» |
| Промпты дневника | **30 шт.** (15 утро / 15 вечер) | вопрос RU/EN + категория | собственные, в духе практик |
| Вопросы ритуалов | утро: 3, вечер: 4 | в словарях i18n | из структуры Stoic-практики |
| Тексты онбординга/подсказок | ~60 строк на язык | в словарях i18n | собственные |

**График наполнения:** цитаты и практики готовятся в спринте 1–2 (параллельно коду), загружаются seed-скриптом в спринте 5.

## 4. Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Бесплатный тир Supabase «засыпает» | Средняя | Cron-ping из GitHub Actions, инструкция в README |
| Переоценка объёма (4 модуля в одном продукте) | Высокая | MoSCoW в ТЗ; MVP — это M-требования, остальное — фаза 2 |
| Контент-долг (цитаты/промпты) | Средняя | Контент-план с дедлайном внутри спринтов; seed-скрипты делают заливку тривиальной |
| Выгорание от «идеального кода» | Средняя | DoD из раздела 08: «работает и протестировано» > «идеально» |
| Изменение тарифов бесплатных сервисов | Низкая | Стек заменяем: схема БД портируема на любой Postgres |
